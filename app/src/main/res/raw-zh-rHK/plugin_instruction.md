3-Slate Studio 是影片與音訊剪輯應用程式, 不安裝 AutoJs6 也可以單獨使用. 它可以剪裁, 拼接, 變速與轉碼影片, 加上水印或轉為 GIF; 也可以剪裁, 混合與轉換音訊, 或在時間線上把多段素材剪輯成片, 配上轉場與字幕. 配合 AutoJs6 時, 腳本可以透過 `video` 與 `audio` 模組完成同樣的處理.

### 開始使用

1. 開啟 3-Slate Studio. 尚未授權時 "媒體庫" 中顯示 "前往授權", 點按後在開啟的系統頁面中允許存取所有檔案.
2. 在 "工具箱" 中選擇一項處理, 例如 "剪輯影片"; 用 "瀏覽檔案" 或 "從媒體庫選擇" 選取素材, 調整選項後點按 "開始處理".
3. 處理時顯示進度, 完成後顯示輸出檔案, 媒體資訊與 "等效腳本"; 所有工作也列在 "工作" 中.
4. 在腳本中使用前, 確認本插件已在 AutoJs6 的 "插件中心" 中啟用.

### 主要功能

- **工具箱**: 每項處理對應一個精靈, 例如 "剪輯影片", "疊加文字與圖片", "轉為 GIF" 與 "混音"; 表單提供預設值與取值範圍.
- **時間線剪輯**: 在 "工具箱" 中點按 "新增剪輯項目", 在影片軌, 音訊軌, 疊加軌與字幕軌上編排素材, 加入轉場, 即時預覽, 復原或重做; "匯出" 後進入工作佇列.
- **字幕**: 在時間線中用 "匯入字幕" 讀入 SRT 或 ASS 檔案, 匯出時繪製到畫面中; "工具箱" 中另有 "燒錄字幕" 與 "字幕格式轉換".
- **錄音**: 點按首頁頂欄的 "錄音" 按鈕或 "工具箱" 中的 "錄音", 從 "麥克風", "內錄" 或 "混合" 錄製 M4A 或 WAV; 可以暫停, 熄屏後繼續錄製.
- **等效腳本**: 精靈, 時間線匯出與錄音的結果都附有 "等效腳本", 可以 "複製", 也可以 "在 AutoJs6 中開啟" 為一個未儲存的新腳本.
- **媒體庫與工作**: "媒體庫" 列出輸出目錄與 AutoJs6 錄製目錄中的媒體, 可以預覽, 分享, 重新命名或 "用工具箱處理"; "工作" 顯示每項工作的進度與失敗原因, 可以取消.
- **設定**: 頂欄的 "設定" 中可以調整外觀, "輸出目錄", "預設影片編碼" 與 "工作並行數" 等; "輸出目錄" 只影響工具箱精靈, 腳本仍使用各自的預設輸出.

### 在腳本中使用

在 AutoJs6 腳本中, 全局模組 `video` 用於處理影片. 下例擷取 `./video.mp4` 從第 2 秒起的 5 秒, 輸出進度並轉為 GIF:

```js
let clip = video.trim("./video.mp4", {
    start: 2000,
    duration: 5000,
    onProgress: (p) => console.log(p.stage, p.percent),
});
let gif = video.toGif(clip.path, { fps: 10, width: 480 });
console.log(gif.path, gif.sizeBytes);
```

`audio` 模組用於處理聲音. 下例把人聲與調低音量的背景音樂混合在一起, 再轉為 FLAC:

```js
let mixed = audio.mix([
    { src: "./voice.m4a" },
    { src: "./music.m4a", volume: 0.3 },
]);
let flac = audio.convert(mixed.path, { format: "flac" });
console.log(flac.path, flac.durationMillis);
```

- 處理方法都有返回 Promise 的 `Async` 形式, 例如 `video.trimAsync`; 同步形式不能在 UI 線程調用. 停止腳本會取消它未完成的工作.
- 相對路徑按腳本工作目錄解析. 省略輸出路徑時, 結果按類型存入 `Movies`, `Music` 或 `Pictures` 中的 3-Slate Studio 資料夾.
- 螢幕錄影 `video.record` 與錄音 `audio.record` 由 AutoJs6 完成, 不需要本插件; 多軌合成用 `video.compose`, 它與時間線剪輯使用相同的項目格式.
- 全部方法與選項見 AutoJs6 文檔的 [video](https://docs.autojs6.com/#/video) 與 [audio](https://docs.autojs6.com/#/audio) 章節.

### 運行要求

- Android 7.0 或更高版本. 插件畫面, 時間線剪輯與錄音不需要 AutoJs6.
- 在腳本中處理需要 AutoJs6 6.8.1 或更高版本, 並在 "插件中心" 中啟用本插件.
- 所有檔案存取權限用於讀寫腳本與畫面指定的檔案, 以及預設輸出目錄.
- 麥克風權限用於插件畫面中的錄音 (內錄也需要); "內錄" 與 "混合" 需要 Android 10 或更高版本, 開始前系統會請你確認螢幕投放.
- 通知權限用於在通知欄顯示較長工作的進度與錄音控制.

### 常見問題

**需要所有檔案存取權限的原因**

插件按腳本或畫面給出的路徑直接讀寫檔案, 預設輸出目錄也位於共用儲存空間. 未授權時處理會回報 `STORAGE_PERMISSION_DENIED`, 並開啟授權頁面.

**時間線匯出回報 `CODEC_ERROR` 時的處理**

裝置能同時使用的編解碼器有限, 重疊的轉場需要同時解碼兩段影片. 減少影片軌或重疊轉場, 或在 "設定" 中把 "工作並行數" 改為 1.

**熄屏後長時間工作被延後或錄音中斷時的處理**

系統的電池最佳化或背景限制可能在熄屏時延後長時間工作或中斷錄音. 點按 "設定" 中的 "電池使用", 在開啟的應用程式資料頁中把電池設為不受限制 (或允許背景活動).

**內錄中部分應用程式沒有聲音的原因**

應用程式可以禁止其他應用程式擷取它播放的聲音, 這類應用程式在內錄中為靜音. 需要錄下這些聲音時改用 "麥克風".

畫面, 權限與等效腳本的詳細說明見 AutoJs6 文檔的 [3-Slate Studio](https://docs.autojs6.com/#/threeSlateStudio) 章節.
