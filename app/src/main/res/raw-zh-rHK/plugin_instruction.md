3-Slate Studio 是 AutoJs6 的影片與音訊插件, 也是不安裝 AutoJs6 也能單獨使用的剪輯應用程式. 它可以剪裁, 拼接, 變速, 縮放, 旋轉, 裁切影片並加上水印, 擷取影格, 轉 GIF 與轉碼; 可以剪裁, 拼接, 混音, 淡入淡出與轉換音訊; 多軌時間線剪輯器把片段與轉場, 疊加和字幕合成為一段影片.

> 目前為開發預覽版: 插件可以被 AutoJs6 插件中心識別, 但處理功能, Studio 畫面與 `video` / `audio` 模組的處理方法尚未交付. 下文描述的是各版本的設計目標, 進度請見開發路線圖.

### 功能亮點

- 影片剪輯: 按時間剪裁, 拼接, 變速 (0.25 到 8 倍), 縮放, 旋轉, 裁切與翻轉, 文字或圖片水印, 擷取或移除音軌, 轉碼 (預設 H.264, 裝置支援時可選 H.265).
- 影格與 GIF: 單一影格, 影格序列與縮圖, 可儲存為圖片檔或傳回 `Image` 物件; 內置編碼器生成 GIF 動畫.
- 音訊: 剪裁, 拼接, 多路混音, 音量調整與淡入淡出, 變速, 轉換為 M4A, WAV, FLAC 或 OGG.
- 多軌時間線: 影片, 音訊與疊加多軌, 7 種轉場 (切換, 淡入淡出, 交叉溶解, 推移, 擦除, 縮放, 模糊), 字幕支援 SRT 匯入匯出與 ASS 基礎子集, 匯出時燒錄進畫面.
- 程式碼生成: 每個工具畫面與時間線匯出都會生成等價的 `video.*` / `audio.*` 程式碼, 可直接複製, 也可在 AutoJs6 中新增為腳本.
- Studio 錄音: 在插件畫面中錄製咪高峰, 裝置內部聲音 (Android 10 或以上) 或兩者混合.
- FFmpeg 大型程式庫 (1.1.0): 按需下載, 提供 MP3, WebM 與 MKV 輸出, `video.ffmpeg` 指令傳遞與完整的 ASS 渲染.

開發進度與設計見 [專案主頁](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Slate-Studio).
