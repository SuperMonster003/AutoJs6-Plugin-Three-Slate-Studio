3-Slate Studio 是视频与音频剪辑应用, 不安装 AutoJs6 也可以单独使用. 它可以裁剪, 拼接, 变速与转码视频, 添加水印或转为 GIF; 也可以裁剪, 混合与转换音频, 或在时间线上把多段素材剪辑成片, 配上转场与字幕. 配合 AutoJs6 时, 脚本可以通过 `video` 与 `audio` 模块完成同样的加工.

### 开始使用

1. 打开 3-Slate Studio. 尚未授权时 "媒体库" 中显示 "去授权", 点按后在打开的系统页面中允许访问所有文件.
2. 在 "工具箱" 中选择一项加工, 例如 "裁剪视频"; 用 "浏览文件" 或 "从媒体库选择" 选取素材, 调整选项后点按 "开始处理".
3. 处理时显示进度, 完成后显示输出文件, 媒体信息与 "等价脚本"; 全部任务也列在 "任务" 中.
4. 在脚本中使用前, 确认本插件已在 AutoJs6 的 "插件中心" 中启用.

### 主要功能

- **工具箱**: 每项加工对应一个向导, 例如 "裁剪视频", "叠加文字与图片", "转为 GIF" 与 "混音"; 表单给出默认值与取值范围.
- **时间线剪辑**: 在 "工具箱" 中点按 "新建剪辑工程", 在视频轨, 音频轨, 叠加轨与字幕轨上编排素材, 添加转场, 实时预览, 撤销或重做; "导出" 后进入任务队列.
- **字幕**: 在时间线中用 "导入字幕" 读入 SRT 或 ASS 文件, 导出时绘制进画面; "工具箱" 中另有 "烧录字幕" 与 "字幕格式转换".
- **录音**: 点按首页顶栏的 "录音" 按钮或 "工具箱" 中的 "录音", 从 "麦克风", "内录" 或 "混合" 录制 M4A 或 WAV; 可以暂停, 熄屏后继续录制.
- **等价脚本**: 向导, 时间线导出与录音的结果都附有 "等价脚本", 可以 "复制", 也可以 "在 AutoJs6 中打开" 为一个未保存的新脚本.
- **媒体库与任务**: "媒体库" 列出输出目录与 AutoJs6 录制目录中的媒体, 可以预览, 分享, 重命名或 "用工具箱处理"; "任务" 显示每个任务的进度与失败原因, 可以取消.
- **设置**: 顶栏的 "设置" 中可以调整外观, "输出目录", "默认视频编码" 与 "任务并发数" 等; "输出目录" 只影响工具箱向导, 脚本仍使用各自的默认输出.

### 在脚本中使用

在 AutoJs6 脚本中, 全局模块 `video` 用于加工视频. 下例截取 `./video.mp4` 从第 2 秒起的 5 秒, 打印进度并转为 GIF:

```js
let clip = video.trim("./video.mp4", {
    start: 2000,
    duration: 5000,
    onProgress: (p) => console.log(p.stage, p.percent),
});
let gif = video.toGif(clip.path, { fps: 10, width: 480 });
console.log(gif.path, gif.sizeBytes);
```

`audio` 模块用于加工声音. 下例把人声与降低音量的背景音乐混在一起, 再转为 FLAC:

```js
let mixed = audio.mix([
    { src: "./voice.m4a" },
    { src: "./music.m4a", volume: 0.3 },
]);
let flac = audio.convert(mixed.path, { format: "flac" });
console.log(flac.path, flac.durationMillis);
```

- 加工方法都有返回 Promise 的 `Async` 形态, 例如 `video.trimAsync`; 同步形态不能在 UI 线程调用. 停止脚本会取消它未完成的任务.
- 相对路径按脚本工作目录解析. 省略输出路径时, 结果按类型存入 `Movies`, `Music` 或 `Pictures` 中的 3-Slate Studio 文件夹.
- 录屏 `video.record` 与录音 `audio.record` 由 AutoJs6 完成, 不需要本插件; 多轨合成用 `video.compose`, 它与时间线剪辑使用相同的工程格式.
- 全部方法与选项见 AutoJs6 文档的 [video](https://docs.autojs6.com/#/video) 与 [audio](https://docs.autojs6.com/#/audio) 章节.

### 运行要求

- Android 7.0 或更高版本. 插件界面, 时间线剪辑与录音不需要 AutoJs6.
- 在脚本中加工需要 AutoJs6 6.8.1 或更高版本, 并在 "插件中心" 中启用本插件.
- 所有文件访问权限用于读写脚本与界面指定的文件, 以及默认输出目录.
- 麦克风权限用于插件界面中的录音 (内录也需要); "内录" 与 "混合" 需要 Android 10 或更高版本, 开始前系统会请你确认屏幕投影.
- 通知权限用于在通知栏显示较长任务的进度与录音控制.

### 常见问题

**需要所有文件访问权限的原因**

插件按脚本或界面给出的路径直接读写文件, 默认输出目录也位于共享存储. 未授权时加工报告 `STORAGE_PERMISSION_DENIED`, 并打开授权页面.

**时间线导出报告 `CODEC_ERROR` 时的处理**

设备能同时使用的编解码器有限, 重叠的转场需要同时解码两段视频. 减少视频轨或重叠转场, 或在 "设置" 中把 "任务并发数" 改为 1.

**熄屏后长任务被推迟或录音中断时的处理**

系统的电池优化或后台限制可能在熄屏时推迟长任务或中断录音. 点按 "设置" 中的 "电池使用", 在打开的应用信息页中把电池设为不受限制 (或允许后台活动).

**内录中部分应用没有声音的原因**

应用可以禁止其他应用捕获它播放的声音, 这类应用在内录中为静音. 需要录下这些声音时改用 "麦克风".

界面, 权限与等价脚本的详细说明见 AutoJs6 文档的 [3-Slate Studio](https://docs.autojs6.com/#/threeSlateStudio) 章节.
