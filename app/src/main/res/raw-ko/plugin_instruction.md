3-Slate Studio는 동영상과 오디오 편집 앱으로, AutoJs6 없이도 단독으로 쓸 수 있습니다. 동영상 자르기, 이어 붙이기, 속도 변경, 트랜스코딩, 워터마크 추가, GIF 변환을 할 수 있고, 오디오 자르기, 믹스, 변환은 물론 타임라인에서 여러 소재에 전환 효과와 자막을 넣어 하나의 동영상으로 편집할 수도 있습니다. AutoJs6와 함께 쓰면 스크립트에서 `video`와 `audio` 모듈로 같은 가공을 할 수 있습니다.

### 시작하기

1. 3-Slate Studio를 엽니다. 아직 권한을 허용하지 않았다면 "라이브러리"에 "권한 허용"이 표시되며, 이를 탭한 뒤 열리는 시스템 화면에서 모든 파일에 대한 접근을 허용합니다.
2. "도구 상자"에서 "동영상 자르기" 같은 가공을 고르고, "파일 찾아보기" 또는 "라이브러리에서 선택"으로 소재를 고른 다음, 옵션을 조정하고 "처리 시작"을 탭합니다.
3. 처리 중에는 진행률이 표시되고, 완료되면 출력 파일, 미디어 정보, "동등한 스크립트"가 표시됩니다. 모든 작업은 "작업"에도 표시됩니다.
4. 스크립트에서 사용하기 전에 AutoJs6의 "플러그인 센터"에서 이 플러그인이 활성화되어 있는지 확인합니다.

### 주요 기능

- **도구 상자**: 가공마다 마법사가 있으며, 예를 들어 "동영상 자르기", "텍스트와 이미지 겹치기", "GIF로 변환", "오디오 믹스" 등이 있습니다. 양식에는 기본값과 허용 범위가 표시됩니다.
- **타임라인 편집**: "도구 상자"에서 "새 타임라인 프로젝트"를 탭하면 비디오, 오디오, 오버레이, 자막 트랙에 소재를 배치하고, 전환 효과를 넣고, 실시간으로 미리 보고, 실행 취소나 다시 실행을 할 수 있습니다. "내보내기"를 하면 결과가 작업 대기열에 들어갑니다.
- **자막**: 타임라인에서 "자막 가져오기"로 SRT 또는 ASS 파일을 읽어 들이면 내보낼 때 화면에 그려 넣습니다. "도구 상자"에는 "자막 입히기"와 "자막 변환"도 있습니다.
- **녹음**: 홈 화면 상단 바의 "녹음" 버튼이나 "도구 상자"의 "녹음"을 탭해 "마이크", "내부 오디오", "혼합" 중 하나에서 M4A 또는 WAV로 녹음합니다. 일시정지할 수 있고 화면이 꺼져도 녹음이 계속됩니다.
- **동등한 스크립트**: 마법사, 타임라인 내보내기, 녹음의 결과에는 "동등한 스크립트"가 함께 표시되며, "복사"하거나 "AutoJs6에서 열기"로 저장되지 않은 새 스크립트로 열 수 있습니다.
- **라이브러리와 작업**: "라이브러리"에는 출력 폴더와 AutoJs6 녹화 폴더의 미디어가 표시되며, 미리 보기, 공유, 이름 바꾸기, "도구 상자로 가공"을 할 수 있습니다. "작업"에는 각 작업의 진행률과 실패 이유가 표시되고 취소할 수 있습니다.
- **설정**: 상단 바의 "설정"에서 모양, "출력 폴더", "기본 비디오 코덱", "동시 작업 수" 등을 바꿀 수 있습니다. "출력 폴더"는 도구 상자 마법사에만 적용되며, 스크립트는 각자의 기본 출력 위치를 사용합니다.

### 스크립트에서 사용하기

AutoJs6 스크립트에서는 전역 모듈 `video`로 동영상을 가공합니다. 아래 예제는 `./video.mp4`의 2초부터 5초 동안을 잘라 내고, 진행률을 출력한 뒤 GIF로 변환합니다:

```js
let clip = video.trim("./video.mp4", {
    start: 2000,
    duration: 5000,
    onProgress: (p) => console.log(p.stage, p.percent),
});
let gif = video.toGif(clip.path, { fps: 10, width: 480 });
console.log(gif.path, gif.sizeBytes);
```

`audio` 모듈은 소리를 가공합니다. 아래 예제는 목소리와 음량을 낮춘 배경 음악을 섞은 뒤 FLAC으로 변환합니다:

```js
let mixed = audio.mix([
    { src: "./voice.m4a" },
    { src: "./music.m4a", volume: 0.3 },
]);
let flac = audio.convert(mixed.path, { format: "flac" });
console.log(flac.path, flac.durationMillis);
```

- 모든 가공 메서드에는 Promise를 반환하는 `Async` 형태 (예: `video.trimAsync`)가 있으며, 동기 형태는 UI 스레드에서 호출할 수 없습니다. 스크립트를 중지하면 완료되지 않은 작업이 취소됩니다.
- 상대 경로는 스크립트의 작업 디렉터리를 기준으로 해석됩니다. 출력 경로를 생략하면 결과는 종류에 따라 `Movies`, `Music`, `Pictures` 안의 3-Slate Studio 폴더에 저장됩니다.
- `video.record`를 통한 화면 녹화와 `audio.record`를 통한 녹음은 AutoJs6가 수행하므로 이 플러그인이 필요하지 않습니다. 멀티트랙 합성에는 `video.compose`를 사용하며, 타임라인 편집과 같은 프로젝트 형식을 씁니다.
- 모든 메서드와 옵션은 AutoJs6 문서의 [video](https://docs.autojs6.com/#/video) 및 [audio](https://docs.autojs6.com/#/audio) 장을 참고하세요.

### 요구 사항

- Android 7.0 이상. 플러그인 화면, 타임라인 편집, 녹음에는 AutoJs6가 필요하지 않습니다.
- 스크립트에서 가공하려면 AutoJs6 6.8.1 이상이 필요하며, "플러그인 센터"에서 이 플러그인을 활성화해야 합니다.
- 모든 파일 접근 권한은 스크립트와 화면에서 지정한 파일, 그리고 기본 출력 폴더를 읽고 쓰는 데 사용합니다.
- 마이크 권한은 플러그인 화면에서 녹음할 때 사용합니다 (내부 오디오에도 필요합니다). "내부 오디오"와 "혼합"에는 Android 10 이상이 필요하며, 시작하기 전에 시스템이 화면 전송 동의를 요청합니다.
- 알림 권한은 긴 작업의 진행률과 녹음 조작 버튼을 알림 창에 표시하는 데 사용합니다.

### 자주 묻는 질문

**모든 파일 접근 권한이 필요한 이유**

플러그인은 스크립트나 화면에서 지정한 경로의 파일을 직접 읽고 쓰며, 기본 출력 폴더도 공유 저장소에 있습니다. 권한이 없으면 가공이 `STORAGE_PERMISSION_DENIED`를 반환하고 권한 화면을 엽니다.

**타임라인 내보내기에서 `CODEC_ERROR`가 반환되는 경우**

기기가 동시에 쓸 수 있는 코덱 수에는 한계가 있으며, 겹치는 전환 효과는 두 동영상을 동시에 디코딩합니다. 비디오 트랙이나 겹치는 전환 효과를 줄이거나, "설정"에서 "동시 작업 수"를 1로 바꾸세요.

**화면이 꺼진 뒤 긴 작업이 지연되거나 녹음이 중단되는 경우**

배터리 최적화나 백그라운드 제한 때문에 화면이 꺼지면 긴 작업이 지연되거나 녹음이 중단될 수 있습니다. "설정"에서 "배터리 사용"을 탭하고, 열리는 앱 정보 화면에서 배터리를 제한 없음 (또는 백그라운드 활동 허용)으로 설정하세요.

**내부 오디오에서 일부 앱의 소리가 녹음되지 않는 이유**

앱은 자신이 재생하는 소리를 다른 앱이 캡처하지 못하도록 막을 수 있으며, 이런 앱은 내부 오디오에서 무음으로 녹음됩니다. 이런 소리를 녹음하려면 "마이크"를 사용하세요.

화면, 권한, 동등한 스크립트에 대한 자세한 내용은 AutoJs6 문서의 [3-Slate Studio](https://docs.autojs6.com/#/threeSlateStudio) 장을 참고하세요.
