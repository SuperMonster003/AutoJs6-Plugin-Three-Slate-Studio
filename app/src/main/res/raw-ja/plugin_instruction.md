3-Slate Studio は動画と音声の編集アプリで, AutoJs6 がなくても単独で使えます. 動画のトリミング, 結合, 速度変更, トランスコード, 透かしの追加, GIF への変換ができ, 音声のトリミング, ミックス, 変換のほか, タイムライン上で複数の素材にトランジションや字幕を付けて 1 本の動画に編集することもできます. AutoJs6 と組み合わせると, スクリプトから `video` と `audio` モジュールで同じ加工を行えます.

### はじめに

1. 3-Slate Studio を開きます. まだ許可していない場合は "ライブラリ" に "許可する" が表示されるので, タップして開いたシステム画面ですべてのファイルへのアクセスを許可します.
2. "ツールボックス" で "動画をトリミング" などの加工を選び, "ファイルを参照" または "ライブラリから選択" で素材を選んで, オプションを調整してから "処理を開始" をタップします.
3. 処理中は進捗が表示され, 完了すると出力ファイル, メディア情報, "同等のスクリプト" が表示されます. すべてのタスクは "タスク" にも一覧表示されます.
4. スクリプトで使う前に, AutoJs6 の "プラグインセンター" で本プラグインが有効になっていることを確認します.

### 主な機能

- **ツールボックス**: 加工ごとにウィザードがあり, 例えば "動画をトリミング", "テキストと画像を重ねる", "GIF に変換", "音声をミックス" などがあります. フォームには既定値と指定できる範囲が表示されます.
- **タイムライン編集**: "ツールボックス" の "新しいタイムラインプロジェクト" をタップし, 映像, 音声, オーバーレイ, 字幕のトラックに素材を配置して, トランジションの追加, リアルタイムのプレビュー, 元に戻す / やり直しができます. "書き出し" で結果がタスクキューに入ります.
- **字幕**: タイムラインの "字幕を読み込む" で SRT または ASS ファイルを読み込み, 書き出し時に映像へ描き込みます. "ツールボックス" には "字幕を焼き込む" と "字幕を変換" もあります.
- **録音**: ホーム画面の上部バーにある "録音" ボタン, または "ツールボックス" の "録音" をタップし, "マイク", "内部音声", "ミックス" のいずれかから M4A または WAV で録音します. 一時停止でき, 画面オフでも録音を続けます.
- **同等のスクリプト**: ウィザード, タイムラインの書き出し, 録音の結果には "同等のスクリプト" が付き, "コピー" するか, "AutoJs6 で開く" で未保存の新しいスクリプトとして開けます.
- **ライブラリとタスク**: "ライブラリ" には出力フォルダーと AutoJs6 の録画フォルダーにあるメディアが並び, プレビュー, 共有, 名前の変更, "ツールボックスで加工" ができます. "タスク" には各タスクの進捗と失敗の理由が表示され, キャンセルもできます.
- **設定**: 上部バーの "設定" で外観, "出力フォルダー", "既定の映像コーデック", "同時実行タスク数" などを変更できます. "出力フォルダー" はツールボックスのウィザードにだけ影響し, スクリプトはそれぞれの既定の出力先を使います.

### スクリプトでの使い方

AutoJs6 のスクリプトでは, グローバルモジュール `video` で動画を加工します. 次の例は `./video.mp4` の 2 秒目から 5 秒間を切り出し, 進捗を出力して GIF に変換します:

```js
let clip = video.trim("./video.mp4", {
    start: 2000,
    duration: 5000,
    onProgress: (p) => console.log(p.stage, p.percent),
});
let gif = video.toGif(clip.path, { fps: 10, width: 480 });
console.log(gif.path, gif.sizeBytes);
```

`audio` モジュールは音声を加工します. 次の例は声と音量を下げた BGM をミックスし, FLAC に変換します:

```js
let mixed = audio.mix([
    { src: "./voice.m4a" },
    { src: "./music.m4a", volume: 0.3 },
]);
let flac = audio.convert(mixed.path, { format: "flac" });
console.log(flac.path, flac.durationMillis);
```

- 加工メソッドにはすべて Promise を返す `Async` 形式 (例: `video.trimAsync`) があり, 同期形式は UI スレッドで呼び出せません. スクリプトを停止すると, 未完了のタスクはキャンセルされます.
- 相対パスはスクリプトの作業ディレクトリを基準に解決されます. 出力パスを省略すると, 結果は種類に応じて `Movies`, `Music`, `Pictures` 内の 3-Slate Studio フォルダーに保存されます.
- `video.record` による画面録画と `audio.record` による録音は AutoJs6 が行うため, 本プラグインは不要です. マルチトラックの合成には `video.compose` を使います. 形式はタイムライン編集のプロジェクトと共通です.
- すべてのメソッドとオプションは AutoJs6 ドキュメントの [video](https://docs.autojs6.com/#/video) と [audio](https://docs.autojs6.com/#/audio) の章を参照してください.

### 動作要件

- Android 7.0 以降. プラグインの画面, タイムライン編集, 録音には AutoJs6 は不要です.
- スクリプトでの加工には AutoJs6 6.8.1 以降が必要で, "プラグインセンター" で本プラグインを有効にしておく必要があります.
- すべてのファイルへのアクセス権限は, スクリプトや画面で指定したファイルと既定の出力フォルダーの読み書きに使います.
- マイク権限はプラグインの画面での録音に使います (内部音声にも必要). "内部音声" と "ミックス" には Android 10 以降が必要で, 開始前にシステムが画面キャストの確認を求めます.
- 通知権限は, 長いタスクの進捗と録音の操作ボタンを通知シェードに表示するために使います.

### よくある質問

**すべてのファイルへのアクセスが必要な理由**

プラグインはスクリプトや画面で指定されたパスのファイルを直接読み書きし, 既定の出力フォルダーも共有ストレージにあるためです. 許可されていない場合, 加工は `STORAGE_PERMISSION_DENIED` を返し, 許可画面を開きます.

**タイムラインの書き出しで `CODEC_ERROR` が返る場合の対処**

端末が同時に使えるコーデックの数には限りがあり, 重なったトランジションは 2 本の動画を同時にデコードします. 映像トラックや重なったトランジションを減らすか, "設定" で "同時実行タスク数" を 1 にしてください.

**画面オフで長いタスクが遅れる場合や録音が止まる場合の対処**

バッテリーの最適化やバックグラウンド制限により, 画面オフ時に長いタスクが遅れたり録音が止まったりすることがあります. "設定" の "バッテリーの使用" をタップし, 開いたアプリ情報画面でバッテリーを制限なし (またはバックグラウンドでの使用を許可) にしてください.

**内部音声で一部のアプリが無音になる理由**

アプリは, 自分が再生する音声を他のアプリにキャプチャさせないように設定できます. そうしたアプリは内部音声では無音になるので, 録音するには "マイク" を使ってください.

画面, 権限, 同等のスクリプトの詳細は AutoJs6 ドキュメントの [3-Slate Studio](https://docs.autojs6.com/#/threeSlateStudio) の章を参照してください.
