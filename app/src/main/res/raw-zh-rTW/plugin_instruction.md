3-Slate Studio 是影片與音訊剪輯應用程式, 不安裝 AutoJs6 也可以單獨使用. 它可以裁剪, 串接, 變速與轉碼影片, 加上浮水印或轉為 GIF; 也可以裁剪, 混合與轉換音訊, 或在時間軸上把多段素材剪輯成片, 配上轉場與字幕. 搭配 AutoJs6 時, 指令碼可以透過 `video` 與 `audio` 模組完成同樣的處理.

### 開始使用

1. 開啟 3-Slate Studio. 尚未授權時 "媒體庫" 中會顯示 "前往授權", 輕觸後在開啟的系統頁面中允許存取所有檔案.
2. 在 "工具箱" 中選擇一項處理, 例如 "剪輯影片"; 用 "瀏覽檔案" 或 "從媒體庫選擇" 選取素材, 調整選項後輕觸 "開始處理".
3. 處理時會顯示進度, 完成後顯示輸出檔案, 媒體資訊與 "等效指令碼"; 所有工作也會列在 "工作" 中.
4. 在指令碼中使用前, 確認本外掛已在 AutoJs6 的 "外掛中心" 中啟用.

### 主要功能

- **工具箱**: 每項處理對應一個精靈, 例如 "剪輯影片", "疊加文字與圖片", "轉為 GIF" 與 "混音"; 表單會提供預設值與取值範圍.
- **時間軸剪輯**: 在 "工具箱" 中輕觸 "新增剪輯專案", 在影片軌, 音訊軌, 疊加軌與字幕軌上編排素材, 加入轉場, 即時預覽, 復原或重做; "匯出" 後進入工作佇列.
- **字幕**: 在時間軸中用 "匯入字幕" 讀入 SRT 或 ASS 檔案, 匯出時繪製到畫面中; "工具箱" 中另有 "燒錄字幕" 與 "字幕格式轉換".
- **錄音**: 輕觸首頁頂端列的 "錄音" 按鈕或 "工具箱" 中的 "錄音", 從 "麥克風", "內錄" 或 "混合" 錄製 M4A 或 WAV; 可以暫停, 螢幕關閉後會繼續錄製.
- **等效指令碼**: 精靈, 時間軸匯出與錄音的結果都附有 "等效指令碼", 可以 "複製", 也可以 "在 AutoJs6 中開啟" 為一個未儲存的新指令碼.
- **媒體庫與工作**: "媒體庫" 列出輸出資料夾與 AutoJs6 錄製資料夾中的媒體, 可以預覽, 分享, 重新命名或 "用工具箱處理"; "工作" 顯示每項工作的進度與失敗原因, 可以取消.
- **設定**: 頂端列的 "設定" 中可以調整外觀, "輸出資料夾", "預設影片編碼" 與 "工作並行數" 等; "輸出資料夾" 只影響工具箱精靈, 指令碼仍使用各自的預設輸出.

### 在指令碼中使用

在 AutoJs6 指令碼中, 全域模組 `video` 用於處理影片. 下例擷取 `./video.mp4` 從第 2 秒起的 5 秒, 輸出進度並轉為 GIF:

```js
let clip = video.trim("./video.mp4", {
    start: 2000,
    duration: 5000,
    onProgress: (p) => console.log(p.stage, p.percent),
});
let gif = video.toGif(clip.path, { fps: 10, width: 480 });
console.log(gif.path, gif.sizeBytes);
```

`audio` 模組用於處理聲音. 下例把人聲與調低音量的背景音樂混合在一起, 再轉為 FLAC:

```js
let mixed = audio.mix([
    { src: "./voice.m4a" },
    { src: "./music.m4a", volume: 0.3 },
]);
let flac = audio.convert(mixed.path, { format: "flac" });
console.log(flac.path, flac.durationMillis);
```

- 處理方法都有傳回 Promise 的 `Async` 形式, 例如 `video.trimAsync`; 同步形式不能在 UI 執行緒呼叫. 停止指令碼會取消它未完成的工作.
- 相對路徑依指令碼工作目錄解析. 省略輸出路徑時, 結果依類型存入 `Movies`, `Music` 或 `Pictures` 中的 3-Slate Studio 資料夾.
- 螢幕錄影 `video.record` 與錄音 `audio.record` 由 AutoJs6 完成, 不需要本外掛; 多軌合成用 `video.compose`, 它與時間軸剪輯使用相同的專案格式.
- 全部方法與選項見 AutoJs6 文件的 [video](https://docs.autojs6.com/#/video) 與 [audio](https://docs.autojs6.com/#/audio) 章節.

### 執行需求

- Android 7.0 或更高版本. 外掛畫面, 時間軸剪輯與錄音不需要 AutoJs6.
- 在指令碼中處理需要 AutoJs6 6.8.1 或更高版本, 並在 "外掛中心" 中啟用本外掛.
- 所有檔案存取權限用於讀寫指令碼與畫面指定的檔案, 以及預設輸出資料夾.
- 麥克風權限用於外掛畫面中的錄音 (內錄也需要); "內錄" 與 "混合" 需要 Android 10 或更高版本, 開始前系統會請你確認螢幕投放.
- 通知權限用於在通知欄顯示較長工作的進度與錄音控制項.

### 常見問題

**需要所有檔案存取權限的原因**

外掛依指令碼或畫面指定的路徑直接讀寫檔案, 預設輸出資料夾也位於共用儲存空間. 未授權時處理會回報 `STORAGE_PERMISSION_DENIED`, 並開啟授權頁面.

**時間軸匯出回報 `CODEC_ERROR` 時的處理**

裝置能同時使用的編解碼器有限, 重疊的轉場需要同時解碼兩段影片. 減少影片軌或重疊轉場, 或在 "設定" 中把 "工作並行數" 改為 1.

**螢幕關閉後長時間工作被延後或錄音中斷時的處理**

系統的電池最佳化或背景限制可能在螢幕關閉時延後長時間工作或中斷錄音. 輕觸 "設定" 中的 "電池使用", 在開啟的應用程式資訊頁中把電池設為不受限制 (或允許背景活動).

**內錄中部分應用程式沒有聲音的原因**

應用程式可以禁止其他應用程式擷取它播放的聲音, 這類應用程式在內錄中會是靜音. 需要錄下這些聲音時改用 "麥克風".

畫面, 權限與等效指令碼的詳細說明見 AutoJs6 文件的 [3-Slate Studio](https://docs.autojs6.com/#/threeSlateStudio) 章節.
