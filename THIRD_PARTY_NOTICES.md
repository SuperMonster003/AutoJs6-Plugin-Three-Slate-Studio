## Native libraries

The plugin has no native code of its own and Media3 brings none. Jetpack Compose UI graphics depends on
`androidx.graphics:graphics-path` (Apache-2.0, listed above), which packages `libandroidx.graphics.path.so` for
arm64-v8a, armeabi-v7a, x86_64 and x86. These four files are the only native libraries in the APK; the release build
checks that they are stored uncompressed and that the 64-bit ones are aligned to 16 KB pages.
